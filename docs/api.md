## Core layer

The pure, file-free core that `sioff.off_targets`, `sioff.accessibility`,
`sioff.index` and `sioff.search` wrap. Functions here take and return in-memory
objects (Polars DataFrames, dicts, generators) and raise plain Python
exceptions.
